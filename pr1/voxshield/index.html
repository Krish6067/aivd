AUDIO SOURCE REQUIREMENTS

Browser microphone access captures your physical microphone input only — it does not automatically include audio from a phone call, VoIP app, or another application. To analyze call audio, route it to a virtual audio device and select it below.

HOW TO ROUTE CALL AUDIO
  1. Windows: Install VB-Audio Virtual Cable (free). Set it as your default playback device in sound settings, then select "CABLE Output" as the input source below.
  2. macOS: Install BlackHole (free, open-source). Create a Multi-Output Device in Audio MIDI Setup. Select BlackHole as the input source below.
  3. Linux: Use a PulseAudio loopback module: pactl load-module module-loopback. Select the loopback source below.
  4. Select the correct virtual device in AUDIO SOURCE below, then click START CALL MONITOR.
